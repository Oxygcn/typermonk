# Автотайпер 0.3: 10–300 WPM, EN/RU, HTML-интерфейс

## Статус и границы

Это комплект исходников и скриптов сборки, а не собранный или интеграционно проверенный Windows-релиз. В архиве нет готового EXE, установленного драйвера или SDK Interception. Проверки в Linux: синтаксис JavaScript, тесты адаптера страницы на макетах, структура XML/JSON и комплектность. C++/MSVC, C#/.NET, реальный драйвер, WebView2 и работа на сайте требуют проверки на Windows.

Обход «Possible bot» не подтверждён и не гарантируется. В проекте нет патча античита, подмены результатов, перехвата серверного протокола, скрытия WebView2 или подтверждённой модели человеческой биометрии. Не выдавайте автоматические результаты за ручные и учитывайте правила сайта.

## Архитектура

- native/engine.cpp: C++17, DLL для Interception, выбор клавиатуры, нажатия/отпускания, Shift, модель задержек, аварийная остановка.
- app: оболочка EXE на C#/.NET 8 WinForms и WebView2. Это не полностью C++ GUI. C# используется для встраивания браузера и HTML, сам ввод реализован на C++.
- app/ui: локальный HTML/CSS/JavaScript-интерфейс. Внешние CDN не используются.
- app/snapshot.js: чтение текущего слова и набранной части непосредственно со страницы Monkeytype.
- build-and-run.bat: проверка компонентов, сборка DLL, сборка EXE, запуск.
- build.bat: только сборка. run.bat: последующие запуски.

Расширение браузера больше не нужно. Monkeytype открывается внутри приложения. Это два WebView2: локальная панель и сайт, а не iframe. Сообщения привилегированного управления принимаются только из локальной панели. Для сайта мост WebMessage отключён, внешняя навигация и всплывающие окна блокируются. Внешняя авторизация намеренно не поддержана. Приложение предназначено для работы с тестом без входа в аккаунт.

## Что установить один раз

1. Windows x64. Совместимость драйвера с конкретной версией ОС нужно проверить отдельно. README Interception заявляет тестирование до Windows 10; это не подтверждение поддержки Windows 11.
2. Visual Studio 2022 или Build Tools 2022 с компонентом разработки классических приложений C++, компилятором x64 и Windows SDK.
3. .NET SDK 8 или новее. Именно SDK нужен для сборки, не только Runtime.
4. WebView2 Evergreen Runtime: https://developer.microsoft.com/microsoft-edge/webview2/
5. Официальный SDK и драйвер Interception: https://github.com/oblitum/Interception/releases

Для установки драйвера откройте терминал администратора, запустите официальный install-interception.exe без аргументов и следуйте его справке. Перезагрузите ОС согласно инструкции установщика. BAT не устанавливает драйвер автоматически, не отключает подписи драйверов, Secure Boot или другие средства защиты.

Пакет WebView2 для сборки закреплён на версии 1.0.2903.40. Это выбранная известная версия, не утверждение о последней версии. Первая сборка загружает NuGet-зависимости и .NET runtime-пакеты из источников, настроенных на вашем ПК. Требуется интернет. При блокировке доступа используйте разрешённый источник пакетов, не отключайте проверки сертификатов.

## Сборка и запуск

Распакуйте архив целиком в обычную папку, желательно с коротким путём, например C:\Tools\Autotyper. Не запускайте BAT непосредственно из просмотра ZIP.

Положите SDK в vendor/Interception, чтобы был файл vendor/Interception/library/interception.h. Можно хранить SDK в другом месте: BAT спросит путь или возьмёт переменную INTERCEPTION_ROOT.

Дважды щёлкните build-and-run.bat. При успехе откроется dist/Autotyper.exe. Журналы компиляции: build/native-build.log и build/desktop-build.log. Если приложение уже запущено, закройте его перед повторной сборкой.

Повторные запуски: run.bat или dist/Autotyper.exe. Папка dist содержит EXE, DLL, HTML и .NET runtime. Не переносите один EXE отдельно. .NET Runtime включается в результат сборки, но WebView2 Runtime и драйвер должны быть установлены на целевом ПК отдельно.

## Использование

1. Дождитесь загрузки Monkeytype во встроенном окне. Закройте мешающие диалоги сайта и выберите обычный английский или русский тест.
2. Выберите English (United States) для английского или стандартную русскую раскладку для русского. Переключайте раскладку в активном окне приложения ДО запуска. Выключите Caps Lock. Автоматического переключения раскладки между языками нет.
3. Задайте целевой темп от 10 до 300 WPM и вариативность. Нажмите «Запустить».
4. В течение 20 секунд нажмите и отпустите F8 в активном окне приложения. Это определяет клавиатуру. Программа фокусирует поле теста и начинает ввод.
5. Esc или F9 останавливает ввод. Кнопка «Стоп», потеря фокуса, навигация и закрытие окна также запрашивают остановку. Перед штатным закрытием программа ждёт возврата движка, чтобы отпустить клавиши.
6. Новый тест требует нового запуска, автоматического бесконечного цикла нет.

Поле GUI забирает фокус у сайта при клике, поэтому открытие панели во время набора может остановить тест. Не печатайте вручную одновременно с программой.

## Модель ритма

Планируются интервалы между началами нажатий, а не дополнительные паузы после каждого обмена с браузером. Удержание клавиши и проверка DOM входят в бюджет интервала. Убраны обязательное ожидание 15 мс после каждого символа и повторное чтение уже полученного состояния DOM. При активной сессии движок запрашивает разрешение системного таймера 1 мс; после сессии запрос снимается.

Целевой интервал: 12000 / WPM миллисекунд, где условное слово равно пяти символам. Например, 180 WPM соответствует 66,7 мс, 300 WPM соответствует 40 мс между началами нажатий. Длительность удержания подстраивается под интервал, а не остаётся фиксированной в диапазоне 35–75 мс.

Реализованы плавный дрейф темпа, логнормальный разброс, поправки на пробелы, повторения и пунктуацию. Средний вес интервала нормализуется скользящей оценкой, чтобы вариативность не означала постоянное снижение скорости. Фактический темп всё равно зависит от страницы, системы, режима теста и задержек WebView2. При перегрузке он будет ниже заданного.

Не допускается неограниченное догоняющее воспроизведение: минимальный интервал составляет 60% базового, а при значительном отставании расписание сбрасывается. Нажатия не перекрываются. Автоматические опечатки и биометрическая калибровка по набору пользователя не реализованы. Прохождение какого-либо детектора не подтверждено.

После каждого символа проверяется изменение DOM. Если подтверждения нет в течение 1,5 секунды, набор прекращается. Чтение страницы имеет отдельный тайм-аут 3 секунды. GUI показывает оценку фактического темпа как число успешно отправленных символов / 5 / минуты. Это не обязательно совпадает с метрикой сайта.

## Поддержка текста и режимов

Поддерживаются английские и русские буквы верхнего/нижнего регистра, включая Ё/ё, а также цифры, обычная ASCII-пунктуация и пробелы. Символы сопоставляются физическим клавишам через VkKeyScanExW для текущей раскладки. Поддержка русских букв в коде не означает поддержку всей кириллицы: украинские и другие дополнительные буквы не добавлены. Диакритика, типографские кавычки, длинное тире, табуляция, переносы строк, Zen и специальные режимы трансформации/скрытия символов не поддерживаются. При несовпадении введённой части с целевым словом программа останавливается.

Адаптер использует #words .word.active, data-wordindex и #wordsInput. Он ориентируется на доступный исходный код сайта, но изменение разметки потребует обновления snapshot.js.

## Журналы и приватность

Настройки GUI сохраняются локально в хранилище WebView2. Профиль встроенного браузера и журналы находятся в %LOCALAPPDATA%\InterceptionAutotyper.

Журнал сессии содержит дату, заданные параметры, количество символов, интервалы обработки и причину остановки. Сам текст и символы в этот журнал не записываются. Профиль браузера отдельно хранит обычные данные сайта. Кнопка «Журнал» открывает локальную папку; ничего автоматически не отправляется разработчику или агенту. При использовании сайта сам сайт получает обычные запросы и введённые данные.

## Безопасность ввода

Interception отправляет системные клавиатурные события. Проверка активного окна не атомарна с отправкой: при переключении возможен редкий ввод не в то поле. Не держите рядом терминал или важные формы, а первые проверки проводите в отдельной сессии. Гарантировать отпускание клавиш при отказе драйвера или принудительном завершении процесса невозможно.

Приложение не требует отключать защиту Windows, не устанавливается в автозагрузку и не изменяет сайт или серверные ответы. Удаление папки проекта не удаляет установленный драйвер: для него используйте официальный установщик.

## Проверки версии 0.3

- 21 сценарий адаптера DOM: английский, русский, Ё/ё, верхний регистр, частично набранный текст, ошибочный текст и неподдерживаемые символы.
- Математическая симуляция расписания при 90, 180 и 300 WPM, а также при перегрузке и разовой задержке.
- Синтаксис JavaScript, XML проекта, соответствие имён экспортов DLL и P/Invoke, отсутствие старого ограничения 180 в коде.

Симуляция не измеряет Windows, WebView2 или Interception и не доказывает достижение 300 WPM на реальном ПК. Компиляция этой версии и интеграционные испытания здесь не выполнялись.

## Обновление с предыдущей версии

Закройте старый EXE. Распакуйте новый ZIP в новую папку и запустите build-and-run.bat. Он заново соберёт typing_engine.dll и Autotyper.exe. Не переносите старую DLL в новую папку. После запуска в заголовке окна должна быть версия 0.3, а поле скорости должно принимать 300.
