# Версия 0.3

Исправлено двойное включение времени обработки в межклавишный интервал. Вместо задержки после удержания/обмена с браузером используется расписание начала нажатий. Удалена обязательная пауза проверки DOM в 15 мс и лишний запрос состояния. Удержание адаптируется к скорости; разрешение системного таймера запрашивается на время набора.

Предел 300 установлен согласованно в HTML, JavaScript, C# и C++. Добавлен русский текст, включая Ё/ё и верхний регистр. Раскладку нужно заранее выбрать вручную: EN-US или RU по языку теста. Смешанный англо-русский текст в одном запуске с автоматическим переключением не реализован.

Сохранены Esc/F9, остановка по потере фокуса, проверка каждого символа и ограничение догоняющих событий. Обход Possible bot не проверен.

Перед обновлением закройте старый EXE и пересоберите проект через build-and-run.bat в новой папке.
